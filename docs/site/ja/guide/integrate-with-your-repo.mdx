<Page>
  <PageHero
    eyebrow="// GUIDE · CI"
    title="自分の CI からレシピを実行する。"
    sub="再利用可能な GitHub Actions ワークフローで、Layer 2 のレシピを自分のリポジトリで実行し、判定を確認できます。"
  />

  <Section
    eyebrow="// 1 · ジョブを追加する"
    heading="ワークフローファイル1つで使えます。"
  >
    <p><a href="/vivarium/ja/repro/">ギャラリー</a>で Layer 2 のレシピを探し、slug を控えます。次の内容を <code>.github/workflows/check-bug.yml</code> として保存します。</p>
    <pre><code>{`name: vivarium-check
on:
  pull_request:
  schedule:
    - cron: '17 4 * * *'
jobs:
  bash-issue:
    uses: aletheia-works/vivarium/.github/workflows/vivarium-verdict.yml@main
    with:
      slug: bash-local-shadows-exit
`}</code></pre>
    <p>ジョブはレシピのイメージを取得して実行し、判定を検証して、期待する判定と比べます。複数のバグを追う場合は、バグごとにジョブを追加します。</p>
    <Callout>
      このワークフローで実行できるのは Layer 2 のレシピだけです。Layer 1 の判定はブラウザで行われるので、実行するイメージがありません。
    </Callout>
  </Section>

  <Section
    eyebrow="// 2 · 結果を読む"
    heading="判定が期待どおりならジョブは成功します。"
  >
    <p>既定では <code>reproduced</code> を期待します。バグが再現しなければ、ジョブは失敗します。</p>
    <p>判定は <code>verdict-&lt;slug&gt;-&lt;run_id&gt;</code> という名前のワークフローアーティファクトに保存されます。</p>
    <Callout>
      既定のイメージは Vivarium 側でレシピが変わったときにだけ更新されます。スケジュール実行だけでは、プロジェクトの新しいリリースには気づきません。自分のビルドを確かめるには、下の <code>image</code> 入力を使います。
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · 自分のビルドを確かめる"
    heading="自分でビルドしたイメージに対して再現を実行する。"
  >
    <p>修正でバグが消えることを確かめるには、ジョブに自分のイメージを指定し、<code>unreproduced</code> を期待します。ランナーは認証なしでイメージを取得するので、公開イメージにしてください。スクリプト自体が失敗しても終了コード 1 は <code>unreproduced</code> になるので、実行の出力も確認してください。0 と 1 以外の終了コードでは、ジョブが失敗します。</p>
    <pre><code>{`jobs:
  check-my-fix:
    uses: aletheia-works/vivarium/.github/workflows/vivarium-verdict.yml@main
    with:
      slug: bash-local-shadows-exit
      image: ghcr.io/you/bash-fix:latest
      expected_verdict: unreproduced
`}</code></pre>
    <NumberedList
      items={[
        {
          lead: 'slug（必須）。',
          body: '実行するレシピです。',
        },
        {
          lead: 'image。',
          body: 'ghcr.io/aletheia-works/vivarium-<slug>:latest の代わりに実行するイメージです。',
        },
        {
          lead: 'expected_verdict。',
          body: 'reproduced（既定）または unreproduced です。',
        },
        {
          lead: 'timeout_minutes。',
          body: 'ジョブのタイムアウトです。既定は5分です。',
        },
      ]}
    />
    <p>詳しくは<a href="/vivarium/ja/spec/consumer-workflow">ワークフローのリファレンス</a>を参照してください。</p>
  </Section>
