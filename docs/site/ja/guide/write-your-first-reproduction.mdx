    <p>実際のシステムが必要なバグには Layer 2 を使います。<code>mise run recipes:new</code> を実行し、<a href="https://github.com/aletheia-works/vivarium/blob/main/src/layer2_docker/README.md">Layer 2 の README</a> に従ってください。</p>
  </Section>

  <Section
    eyebrow="// 2 · レシピをコピーする"
    heading="同じ言語のレシピから始めます。"
  >
    <p><a href="https://github.com/aletheia-works/vivarium/blob/main/CONTRIBUTING.md">CONTRIBUTING.md</a> の手順で環境を整え、<code>src/layer1_wasm/</code> のディレクトリを <code>&lt;project&gt;-&lt;issue&gt;</code> という名前でコピーします。</p>
    <ul>
      <li>Python: <code>pandas-56679</code></li>
      <li>Ruby: <code>ruby-21709</code></li>
      <li>コマンドラインツール: <code>jj-10189</code></li>
    </ul>
    <p>次のファイルを編集します。</p>
    <ul>
      <li><code>repro.ts</code>: 再現の内容と、結果から判定を作る処理です。</li>
      <li><code>page.en.html</code>: ページの文章です。</li>
      <li><code>i18n.ja.json</code>: 日本語の文章です。</li>
      <li><code>recipe.json</code>: 言語、症状、深刻度、タグです。</li>
      <li><code>README.md</code>: バグの説明です。最初の見出しがレシピのタイトルになります。</li>
    </ul>
    <Callout>
      <code>index.html</code> は編集しないでください。<code>page.en.html</code> から生成されます。
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · 再現を書く"
    heading="起きたことを出力し、結果をグローバル変数に残します。"
  >
    <p>Python のレシピでは、<code>repro.ts</code> 内のスクリプトを置き換えます。</p>
    <pre><code>{`import pandas as pd

left = ...
right = ...
mismatch = left != right

result = {
    "left": left,
    "right": right,
    "mismatch": mismatch,
}

print("left ".ljust(10) + str(left))
print("right".ljust(10) + str(right))
print("The two disagree." if mismatch else "The two agree.")
`}</code></pre>
    <ul>
      <li><strong>起きたことを出力します。</strong> ページにはスクリプトの実際の出力が表示されるので、訪問者は判定の理由を確認できます。</li>
      <li><strong>値を <code>result</code> というグローバル変数に入れます。</strong> ページはこの値から判定を作ります。</li>
    </ul>
    <p>コピーした <code>repro.ts</code> のその他の部分はそのまま残します。<a href="/vivarium/ja/spec/contract-v1">Contract v1</a> の形式で判定を報告する処理です。</p>
  </Section>

    <p>続けて型チェックを実行します。</p>
