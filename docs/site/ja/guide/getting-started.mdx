  <Section
    eyebrow="// 2 · 結果を読む"
    heading="判定の意味。"
  >
    <ul>
      <li><code>reproduced</code>: バグが起きます。</li>
      <li><code>unreproduced</code>: バグが起きません。プロジェクトの新しいバージョンで直っている場合があります。</li>
      <li><code>pending</code>: 実行がまだ終わっていません。</li>
    </ul>
    <p>判定の根拠になった出力も同じページにあるので、結果を自分で確認できます。</p>
    <Callout>
      バグを確かめる前に実行が失敗した場合も <code>unreproduced</code> になり、この結果はバグの有無を示しません。出力にレシピの通常の結果ではなくエラーが表示されていたら、ページを再読み込みして、もう一度試してください。
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · DOCKER で動かす"
    heading="Layer 2 のレシピは手元で動かします。"
  >
    <p>Layer 2 と表示されたレシピは実際のシステムが必要なので、イメージで提供しています。Docker をインストールした環境で、次のコマンドを実行します。</p>
    <pre><code>{`docker run --rm ghcr.io/aletheia-works/vivarium-bash-local-shadows-exit:latest
`}</code></pre>
    <p>出力の最後の行に判定が表示されます。</p>
