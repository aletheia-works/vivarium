<Page>
  <PageHero
    eyebrow="// GUIDE · CI"
    title="Run a recipe from your own CI."
    sub="A reusable GitHub Actions workflow runs a Layer 2 recipe in your repository and checks its verdict."
  />

  <Section
    eyebrow="// 1 · ADD THE JOB"
    heading="One workflow file is enough."
  >
    <p>Find a Layer 2 recipe in the <a href="/vivarium/repro/">gallery</a> and note its slug. Then save this as <code>.github/workflows/check-bug.yml</code>:</p>
    <pre><code>{`name: vivarium-check
on:
  pull_request:
  schedule:
    - cron: '17 4 * * *'
jobs:
  bash-issue:
    uses: aletheia-works/vivarium/.github/workflows/vivarium-verdict.yml@main
    with:
      slug: bash-local-shadows-exit
`}</code></pre>
    <p>The job pulls the recipe's image, runs it, validates the verdict and compares it with the verdict you expect. To track several bugs, add one job for each.</p>
    <Callout>
      This workflow runs Layer 2 recipes only. A Layer 1 verdict is computed in a browser, so there is no image to run.
    </Callout>
  </Section>

  <Section
    eyebrow="// 2 · READ THE RESULT"
    heading="The job passes when the verdict is what you expected."
  >
    <p>By default, the job expects <code>reproduced</code>. If the bug does not reproduce, the job fails.</p>
    <p>The verdict is saved as a workflow artifact named <code>verdict-&lt;slug&gt;-&lt;run_id&gt;</code>.</p>
    <Callout>
      The default image changes only when the recipe changes in Vivarium, so a schedule alone will not notice a new release of the project. To check your own build, use the <code>image</code> input below.
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · CHECK YOUR OWN BUILD"
    heading="Run the reproduction against an image you built."
  >
    <p>To check that your fix removes the bug, point the job at your image and expect <code>unreproduced</code>. The runner pulls the image without credentials, so it must be public. Any non-zero exit code counts as <code>unreproduced</code>, so also check the output of the run.</p>
    <pre><code>{`jobs:
  check-my-fix:
    uses: aletheia-works/vivarium/.github/workflows/vivarium-verdict.yml@main
    with:
      slug: bash-local-shadows-exit
      image: ghcr.io/you/bash-fix:latest
      expected_verdict: unreproduced
`}</code></pre>
    <NumberedList
      items={[
        {
          lead: 'slug (required).',
          body: 'The recipe to run.',
        },
        {
          lead: 'image.',
          body: 'The image to run instead of ghcr.io/aletheia-works/vivarium-<slug>:latest.',
        },
        {
          lead: 'expected_verdict.',
          body: 'reproduced (the default) or unreproduced.',
        },
        {
          lead: 'timeout_minutes.',
          body: 'The job timeout. The default is 5.',
        },
      ]}
    />
    <p>See the <a href="/vivarium/spec/consumer-workflow">workflow reference</a> for details.</p>
  </Section>
</Page>
