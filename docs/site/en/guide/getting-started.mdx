  <Section
    eyebrow="// 2 · READ THE RESULT"
    heading="What the verdict means."
  >
    <ul>
      <li><code>reproduced</code>: the bug happens.</li>
      <li><code>unreproduced</code>: the bug does not happen. A newer version of the project may have fixed it.</li>
      <li><code>pending</code>: the run has not finished.</li>
    </ul>
    <p>The output the verdict is based on is on the same page, so you can check the result yourself.</p>
    <Callout>
      If the page says <strong>Not judged</strong>, the run itself failed, which says nothing about the bug. Reload the page to try again.
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · RUN ONE IN DOCKER"
    heading="Layer 2 recipes run on your machine."
  >
    <p>A recipe marked Layer 2 needs a real system, so it ships as an image. With Docker installed, run:</p>
    <pre><code>{`docker run --rm ghcr.io/aletheia-works/vivarium-bash-local-shadows-exit:latest
`}</code></pre>
    <p>The last line of the output states the verdict.</p>
  </Section>
