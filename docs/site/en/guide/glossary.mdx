<Page>
  <PageHero
    eyebrow="// GUIDE · GLOSSARY"
    title="The terms Vivarium uses."
    sub="What each word means on this site."
  />

  <Section
    eyebrow="// BASICS"
    heading="Terms you will see on most pages."
  >
    <dl className="v-glossary">
      <dt id="recipe"><strong>Recipe</strong></dt>
      <dd>
        One reproduction of one bug. The catalogue is the set of all recipes.
      </dd>

      <dt id="slug"><strong>Slug</strong></dt>
      <dd>
        A recipe's identifier, such as <code>pandas-56679</code> or{' '}
        <code>bash-local-shadows-exit</code>. Tools use it to refer to a recipe.
      </dd>

      <dt id="layer"><strong>Layer</strong></dt>
      <dd>
        Where a recipe runs. Layer 1 runs in your browser through WebAssembly.
        Layer 2 runs in Docker on your machine. Layer 3 is a live preview of a
        pull request's whole application, open only to invited people. See{' '}
        <a href="/vivarium/architecture">How it works</a>.
      </dd>

      <dt id="verdict"><strong>Verdict</strong></dt>
      <dd>
        The result of running a recipe. <code>reproduced</code> means the bug
        happens. <code>unreproduced</code> means it did not, either because it is
        absent or because the run failed before reaching it, so check the
        output. The words describe the bug, not a test, so
        <code>reproduced</code> is not a good outcome for the project. See{' '}
        <a href="/vivarium/spec/contract-v1#verdict-semantics">verdict semantics</a>.
      </dd>

      <dt id="evidence"><strong>Evidence</strong></dt>
      <dd>
        The output a verdict is based on, such as standard output, standard
        error, the exit code and the duration.
      </dd>
    </dl>
  </Section>

  <Section
    eyebrow="// VERIFYING A FIX"
    heading="Terms for checking a change."
  >
    <dl className="v-glossary">
      <dt id="branch-fix"><strong>Branch fix</strong></dt>
      <dd>
        A candidate fix built from a branch. If the verdict changes from{' '}
        <code>reproduced</code> to <code>unreproduced</code>, the fix works for
        this bug. See <a href="/vivarium/guide/compare-branch-fix">Verify a branch fix</a>.
      </dd>

      <dt id="consumer-workflow"><strong>Consumer workflow</strong></dt>
      <dd>
        A reusable GitHub Actions workflow that runs a Layer 2 recipe from your
        own repository's CI. See{' '}
        <a href="/vivarium/spec/consumer-workflow">Consumer workflow</a>.
      </dd>
    </dl>
  </Section>

  <Section
    eyebrow="// FOR TOOLS"
    heading="Formats that tools read."
  >
    <dl className="v-glossary">
      <dt id="contract"><strong>Contract</strong></dt>
      <dd>
        How every recipe reports its verdict, so tools can read any of them in
        the same way. See <a href="/vivarium/spec/contract-v1">Contract v1</a>.
      </dd>

      <dt id="recipes-index"><strong>Recipes index</strong></dt>
      <dd>
        The catalogue as data, at{' '}
        <a href="https://aletheia-works.github.io/vivarium/api/recipes.json"><code>/api/recipes.json</code></a>.
        See <a href="/vivarium/spec/recipes-index-v1">Recipes index v1</a>.
      </dd>
    </dl>
  </Section>
</Page>
