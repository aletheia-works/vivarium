  <Section
    eyebrow="// 1 · READ THE RESULT"
    heading="A working fix changes the verdict."
  >
    <ul>
      <li><strong><code>reproduced</code> → <code>unreproduced</code>:</strong> the fix removes the bug.</li>
      <li><strong><code>reproduced</code> → <code>reproduced</code>:</strong> the fix did not change the outcome.</li>
      <li><strong><code>unreproduced</code> → <code>reproduced</code>:</strong> the change introduced the bug.</li>
      <li><strong><code>unreproduced</code> → <code>unreproduced</code>:</strong> the bug was already absent, so this run says nothing about the fix.</li>
    </ul>
  </Section>

  <Section
    eyebrow="// 2 · LAYER 2"
    heading="Build an image with the fix and compare."
  >
    <NumberedList

        },
        {
          lead: 'Run the workflow.',
          body: <>Run <code>gh workflow run branch-fix-verdict.yml --repo aletheia-works/vivarium -f slug=&lt;slug&gt; -f branch_image=&lt;your-image&gt;</code>. This needs write access to the repository. Without it, enable Actions on your own fork and use <code>--repo &lt;you&gt;/vivarium</code>.</>,
        },
        {
          lead: 'Download the artifact.',
