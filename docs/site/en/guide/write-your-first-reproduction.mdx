    eyebrow="// GUIDE · ADD A REPRODUCTION"
    title="Write a recipe that runs in the browser."
    sub="Copy the closest existing recipe, replace the reproduction, and check it locally. This guide covers Layer 1, the easiest place to start."
  />

  <Section
    eyebrow="// 1 · PICK A BUG"
    heading="A good first recipe is small and deterministic."
  >
    <ul>
      <li>It needs no network, no external services and no subprocesses.</li>
      <li>The result comes down to one yes-or-no question, such as "are these two values equal?"</li>
      <li>The library it needs is available in the browser runtime.</li>
    </ul>
    <p>For bugs that need a real system, use Layer 2 instead. Run <code>mise run recipes:new</code> and follow the <a href="https://github.com/aletheia-works/vivarium/blob/main/src/layer2_docker/README.md">Layer 2 README</a>.</p>
  </Section>

  <Section
    eyebrow="// 2 · COPY A RECIPE"
    heading="Start from one in the same language."
  >
    <p>Follow the setup in <a href="https://github.com/aletheia-works/vivarium/blob/main/CONTRIBUTING.md">CONTRIBUTING.md</a>, then copy a directory under <code>src/layer1_wasm/</code> to a new one named <code>&lt;project&gt;-&lt;issue&gt;</code>:</p>
    <ul>
      <li>Python: <code>pandas-56679</code></li>
      <li>Ruby: <code>ruby-21709</code></li>
      <li>A command-line tool: <code>jj-10189</code></li>
    </ul>
    <p>Edit these files:</p>
    <ul>
      <li><code>repro.ts</code>: the reproduction and how its result becomes a verdict.</li>
      <li><code>page.en.html</code>: the text on the page.</li>
      <li><code>i18n.ja.json</code>: the Japanese text.</li>
      <li><code>recipe.json</code>: the language, symptom, severity and tags.</li>
      <li><code>README.md</code>: the bug. Its first heading becomes the recipe's title.</li>
    </ul>
    <Callout>
      Do not edit <code>index.html</code>. It is generated from <code>page.en.html</code>.
    </Callout>
  </Section>

  <Section
    eyebrow="// 3 · WRITE THE REPRODUCTION"
    heading="Print what happened, and leave the result in a global."
  >
    <p>For a Python recipe, replace the script in <code>repro.ts</code>:</p>
    <pre><code>{`import pandas as pd

left = ...
right = ...
mismatch = left != right

result = {
    "left": left,
    "right": right,
    "mismatch": mismatch,
}

print("left ".ljust(10) + str(left))
print("right".ljust(10) + str(right))
print("The two disagree." if mismatch else "The two agree.")
`}</code></pre>
    <ul>
      <li><strong>Print what happened.</strong> The page shows the script's real output, so a visitor can see why the verdict is what it is.</li>
      <li><strong>Assign the values to a global named <code>result</code>.</strong> The page builds the verdict from it.</li>
    </ul>
    <p>Keep the rest of the copied <code>repro.ts</code>. It reports the verdict in the form that <a href="/vivarium/spec/contract-v1">Contract v1</a> describes.</p>
  </Section>

  <Section
    eyebrow="// 4 · CHECK IT LOCALLY"
    heading="See it in the gallery."
  >
    <pre><code>{`mise run docs:dev
`}</code></pre>
    <p>Open <code>http://localhost:3000/vivarium/repro/</code>, find your recipe and open it. The verdict should settle to what you expect, and the output should explain why.</p>
    <p>Then run the type check:</p>
    <pre><code>{`mise run repro:typecheck
`}</code></pre>
  </Section>
