Python recipes use <a href="https://pyodide.org">Pyodide</a>, Ruby recipes use <a href="https://github.com/ruby/ruby.wasm">Ruby.wasm</a>, and command-line tools use <a href="https://www.npmjs.com/package/@aletheia-works/formicarium">formicarium</a>, which runs Linux programs in the browser.</p>

  <Section
    eyebrow="// 02 · LAYER 2"

  >
    <p>Each recipe page has a <code>docker run</code> command for a published image and shows the verdict from the latest CI run. Run the command to confirm that verdict yourself.</p>
    <p>Examples:</p>
    <LiveExamples layer={2} lang="en" />
  </Section>

  <Section
    eyebrow="// 03 · LAYER 3"
    heading="A pull request you can use."
  >
    <p>A preview builds a pull request's application at one commit, backend included, so a reviewer can try the change instead of reading about it. It starts on the first request and suspends when idle.</p>
    <Callout>
      Opening a preview needs a GitHub sign-in. Only the pull request's author, the project's listed maintainers and people named on the preview can enter. A preview has no verdict.
    </Callout>
  </Section>
