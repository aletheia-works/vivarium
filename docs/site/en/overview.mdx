Run it and it gives a <strong>verdict</strong>: <code>reproduced</code> if the bug happens, <code>unreproduced</code> if it does not. The output the verdict is based on sits beside it, so you can check the result yourself.</p>
    <p>Use it to find out whether a reported bug is real, whether it still happens, and whether a fix makes it go away.</p>
    <Callout>
      Every recipe reports its verdict in the same way, so people and tools can read any of them without learning each project first.
    </Callout>
